The Faved Chrome extension saves any page to Faved in one click, from Chrome's toolbar or with a keyboard shortcut.

## Install the extension

<Screenshot
  src="/static/images/docs/cloud/chrome-extension-card.webp"
  alt="The Chrome Extension card in Settings › Integrations, with the Add to Chrome button"
  width={800}
/>

<Steps>
  <Step title="Open the Chrome Web Store page">
    Go to **Settings › Integrations › Chrome Extension** and click **Add to Chrome**, or open the
    [Faved extension in the Chrome Web
    Store](https://chromewebstore.google.com/detail/faved-%E2%80%94-save-bookmarks-li/lejmncpaclknlpnpfinmpnfppaokidmi).
  </Step>
  <Step title="Add it to Chrome">
    Click **Add to Chrome**, then confirm with **Add extension**.
  </Step>
  <Step title="Pin it to the toolbar">
    Click the puzzle-piece **Extensions** icon next to the address bar and pin Faved, so it's always
    one click away.
  </Step>
</Steps>

## Save a page

<Steps>
  <Step title="Open the page you want to save">Browse to any page in Chrome.</Step>
  <Step title="Click the Faved icon">
    Click the Faved icon in the toolbar, or press the extension's keyboard shortcut.
  </Step>
  <Step title="Select the record type">
    The save form opens with the page's details. Under **Type**, choose what kind of page this is,
    such as a product, recipe, or a simple bookmark. The form shows that type's fields.
  </Step>
  <Step title="Fill in the fields and save">
    Extract the fields from the page or fill them in manually, then click **Save**.
  </Step>
</Steps>

> [!TIP]
> The extension saves the page exactly as you're viewing it, including pages you can only see when signed in. Use it whenever a page needs a login or sits on a private network.

> [!TIP]
> To set or change the keyboard shortcut, open `chrome://extensions/shortcuts` in Chrome and find Faved.

Not using Chrome? The [bookmarklet](/docs/cloud/saving-pages/using-browser-bookmarklet) works in every browser, desktop and mobile.
