There are several ways to get a page into Faved. All of them open the same form, where you pick a type, extract fields from the page and save.

The form adapts to the record's type: it shows your global fields plus the fields of the type you pick, and switches to the new type's fields as soon as you choose another one.

## Ways to save

| Method                                                                | Works on                                         |
| --------------------------------------------------------------------- | ------------------------------------------------ |
| [In the app](/docs/cloud/saving-pages/saving-in-the-app)              | Faved on the web, or the installed app           |
| [Chrome extension](/docs/cloud/saving-pages/chrome-extension)         | Chrome on desktop                                |
| [Bookmarklet](/docs/cloud/saving-pages/using-browser-bookmarklet)     | Any desktop or mobile browser                    |
| [Apple Shortcut](/docs/cloud/saving-pages/saving-with-apple-shortcut) | iPhone, iPad and Mac, from the Share Sheet       |
| [Android share](/docs/cloud/saving-pages/android-share)               | Any Android app, once the Faved app is installed |

You'll find the bookmarklet, extension, shortcut and app in **Settings › Integrations**, under **Apps & extensions**. You can also open it from the user menu with **Install apps & extensions**.

## Pages behind a login

The [Chrome extension](/docs/cloud/saving-pages/chrome-extension) and the [bookmarklet](/docs/cloud/saving-pages/using-browser-bookmarklet) save the page exactly as you're viewing it, including pages you can only see when signed in. The other ways can't reach pages behind a login or a firewall, so use one of these two for them.
