The Faved bookmarklet saves the page you're on to Faved with a single click, in any browser.

> [!NOTE]
> A bookmarklet is a bookmark stored in a web browser that contains JavaScript commands that execute when you click it.
> Unlike a browser extension, bookmarklet is lightweight and secure, as it doesn't add any elements or scripts on page, and can only access the page when you run it.
>
> - Has no access to your page data until it is activated
> - Doesn't require installing any browser extensions
> - Works in all modern desktop and mobile browsers

## Install the bookmarklet

Go to **Settings** in Faved and navigate to the **Integrations → Bookmarklet** section. There you'll find the **Add to Faved** button along with its code.

Then install it using the method that fits your device.

### Install on desktop (drag and drop)

Drag the **Add to Faved** button to your browser's bookmarks bar to install it.

If your bookmarks bar isn't visible, enable it in your browser settings — usually under **View → Bookmarks Bar** or **Favourites Bar**.

If drag-and-drop doesn't work, or you'd rather not use the bookmarks bar, follow the manual steps below.

### Install on mobile (or manually)

<Steps>

<Step title="Copy the bookmarklet code">

Click **Code** to reveal the bookmarklet code, then click **Copy**. If the code isn't copied, select it in the field and copy it manually.

</Step>

<Step title="Add a new bookmark">

Add a new bookmark in your browser.

</Step>

<Step title="Paste the code as the bookmark URL">

Paste the copied code into the bookmark's URL (address) field.

</Step>

<Step title="Name and save the bookmark">

Give the bookmark a name, for example "Add to Faved", then save it.

</Step>

</Steps>

## Use the bookmarklet

<Steps>

<Step title="Click the bookmarklet on any page you want to save">

While browsing the web, click **Add to Faved** on any page you'd like to save.

</Step>

<Step title="Confirm in the window">

A window opens with the page's details, read from the page as you see it. On mobile, it opens in a new tab instead.

</Step>

<Step title="Fill in the fields, then save">

Choose a type, extract the page into its fields or fill them in, then click **Save**. The page will be stored and available in Faved.

</Step>

</Steps>

> [!TIP]
> The bookmarklet hands Faved the page exactly as you see it, signed in and with its scripts run. That means extraction works on pages Faved couldn't fetch on its own, such as pages behind a login. Pages up to 32 MB can be handed over.

If you installed the bookmarklet a while ago, the save window may say **This bookmarklet is an older one**. Click **Get the new bookmarklet** and replace it, so it hands pages over this way.
