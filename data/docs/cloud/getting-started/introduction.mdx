## What is Faved Cloud?

Faved Cloud is a bookmark manager that turns web pages into structured records. Every page you save becomes a **record**. Give it a **type**, such as a product, a recipe or a job posting, and the record gets that type's **fields**. Faved can then read the page and fill those fields in for you.

Fields are whatever you want to keep about a page. For example:

| Type                | Fields you might give it                                      |
| ------------------- | ------------------------------------------------------------- |
| Product             | Price, Brand, Rating, Availability, Screenshot                |
| Real estate listing | Address, Price, Bedrooms, Area, Features                      |
| Job posting         | Company, Location, Workplace type, Salary range, Apply link   |
| Recipe              | Cuisine, Prep time, Servings, Diet, Ingredients               |
| Article             | Author, Published date, Topic, Summary, Content, Reading time |
| Event               | Start date, Venue, City, Ticket price, Ticket link            |

A field can hold text, a number with a unit (€, kg, min), a date, a yes/no checkbox, a link, or one or more options from a list you define. You can also save the page's short **summary**, the full **content** as Markdown, and a **screenshot**.

## Key concepts

- **Saving.** Save pages from wherever you are: the **Add** button in the app, the [bookmarklet](/docs/cloud/saving-pages/using-browser-bookmarklet) in any browser, the [Chrome extension](/docs/cloud/saving-pages/chrome-extension), the [Apple Shortcut](/docs/cloud/saving-pages/saving-with-apple-shortcut) on iPhone, iPad and Mac, or the [Share menu on Android](/docs/cloud/saving-pages/android-share). You can also [import bookmarks](/docs/cloud/guides/importing) from your browser, Raindrop.io or Pocket. See [Saving pages](/docs/cloud/saving-pages/overview).
- **Records.** A record is a saved web page: its link, title, description and preview image, plus whatever fields its type adds. See [Records](/docs/cloud/guides/records).
- **Types.** A type decides which fields its records carry. Start from a preset (Product, Real estate listing, Job posting, Article, Recipe, Event) or build your own. See [Types and fields](/docs/cloud/guides/types-and-fields).
- **Fields.** A field belongs to one type, or is **global** and sits on every record. Global fields group records of any type together, such as by **Project**, or by Home, Work and Hobby. See [Types and fields](/docs/cloud/guides/types-and-fields#global-fields-and-type-fields).
- **Extract.** Faved reads a page and fills in the fields you pick, for a single record or many at once. See [Extracting from pages](/docs/cloud/guides/extracting-from-pages).
- **Views.** Each type keeps its own columns, layout and filters, so a list of products can look like a catalogue and a list of recipes like a cookbook. See [Finding and viewing records](/docs/cloud/guides/finding-and-viewing).
