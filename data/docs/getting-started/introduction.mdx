## What is Faved?

Self-hosted Faved is the classic, open-source Faved bookmark manager. You save links, sort them with nested tags, and open them from a browser on your desktop or phone.

There are two ways to use it:

- **Self-host it for free.** Faved is open-source and runs on your own computer, server, or cloud infrastructure, so your bookmarks live in your own database. Nobody else sees what you save, and your library doesn't depend on a company staying in business.
- **Or use Faved Cloud.** [Faved Cloud](https://app.faved.to/signup) adds types, fields and AI extraction, with hosting, backups, updates and email support included. Start with a 14-day free trial, then plans from $5 a month. See the [Faved Cloud docs](/docs/cloud/getting-started/introduction).

Faved Cloud is now its own edition with types, fields and AI extraction. Self-hosted Faved stays the classic bookmark manager. You can bring a Cloud library to self-hosted Faved at any time: export it from Cloud as a bookmarks file and [import it](/docs/guides/importing-bookmarks#import-from-your-browser) here. Export from self-hosted Faved is planned.

## Key features

- **Nested tags**: Nest tags as deep as you like, give them colors, and pin the ones you use most to the top of the sidebar. A parent tag can also show everything filed under its children.

- **Page details filled in for you**: Faved fetches the title, description and preview image when you add a link, and warns you if you've already saved it.

- **Search and sorting**: Search runs as you type and matches the URL, title, description and notes. Sort by date created, date updated, title, description, URL or notes.

- **Bulk actions**: Select many bookmarks and delete them, change their tags or refetch their metadata in one go.

- **Works on any device**: The interface adapts to desktop, tablet and phone. You can also [install it as a PWA](/docs/getting-started/installing-as-a-pwa-app) so it opens like an app, without an app store.

- **Light and dark mode**: Follows your system's light or dark setting automatically.

- **Integrations**: Save the current page in one click with the <a href={siteMetadata.chromeExtensionUrl} target="_blank" rel="noopener">Chrome extension</a>, save from any browser with a lightweight bookmarklet, or send links via the native Share menu on iPhone, Mac, and iPad.

- **Import**: Bring in bookmarks from Chrome, Safari, Firefox or Edge, where folders become nested tags. Moving from Raindrop.io or Pocket? Your tags and collections come along too.

- **Open source**: Read the code, change it, and run your own version.


## Who is Faved for?

- **Researchers and heavy savers**: Keep a large library of sources sorted with nested tags, and find any link again with search.

- **Developers**: Keep documentation, tutorials and code references under tags like `Programming Languages/Backend/Go`, and run Faved with a single Docker command.

- **Self-hosters**: Run Faved on your own hardware. Your bookmarks stay private, and a shutdown, lock-in or price increase somewhere else can't take them away.

- **Teams**: Faved for teams is available on Faved Cloud only. [Get in touch](mailto:hello@faved.to?subject=Faved%20for%20Teams%20request) and we'll help set it up.
